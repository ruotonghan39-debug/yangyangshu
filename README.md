# 痒痒鼠 · 平安手帖

阴阳师个人待办与资源管理网页。本地优先，原生 HTML / CSS / JavaScript，无依赖，不需要安装 Node 或运行服务器。

## 在线访问与部署

在线地址：https://ruotonghan39-debug.github.io/yangyangshu/

代码保存在公开 GitHub 仓库，网页通过 GitHub Pages 部署。发布源为 `main` 分支的根目录；修改代码后提交并推送到 `main`，GitHub 会自动更新网站。`.nojekyll` 用于直接发布原生静态文件。

本地网页的数据不会自动迁移到在线地址；请先导出备份，再在在线网页导入。

## 开始使用

双击本目录的 `index.html`，使用常用浏览器打开。建议固定使用同一个浏览器、同一个文件路径。浏览器若限制本地文件存储，可用 Python 启动预览：

```sh
cd ~/Documents/痒痒鼠
python3 -m http.server 8765 --bind 127.0.0.1
```

再访问 http://127.0.0.1:8765 。按 Ctrl+C 停止。文件入口与 HTTP 入口的数据彼此独立，切换时请先导出，再在新入口导入。

## 已实现

- 游戏资料：在左上方设置并展示游戏名称、等级，支持修改与清空；本地持久化，随备份导出和恢复。旧版数据自动显示未设置状态，不影响原有记录。
- PC 左侧固定导航，插画作为淡化背景；每日待办采用紧凑双栏，备注点击奖励说明展开，手机自动切换单栏。
- 阵容码管理：支持文本、图片或混合保存，新增、编辑、删除、搜索、自定义玩法分类、复制文本、图片放大预览及下载。
- 每日 / 每周待办：勾选、取消、搜索、状态筛选、添加、编辑、删除。
- 北京时间自动切换周期：默认每日 00:00；每周一重置周常。设置可修改重置小时。关闭网页期间无需运行，再次打开自动显示新周期。
- 历史记录：周期状态独立保存，记录勾选、取消、删除操作，支持按游戏日筛选。
- 奖励追踪：地域鬼王、秘闻竞速和分享、式神图鉴分享、常驻黑蛋黑碎检查项、一次性成就及手动刷新商店。
- 资源账本：勾玉、金币、蓝票、体力、黑蛋、黑碎；金币和体力按「万」显示与输入，支持 4 位小数，其余资源不显示量词。原有余额和账本仍按游戏原始整数保存，无需迁移；更新余额自动记录差值、备注和当时余额。
- 黑碎进度：每 50 片记一次合成，扣除 50 黑碎、增加 1 黑蛋。请在游戏中实际合成后操作。
- JSON 完整备份 v2：保存任务、状态、历史、资源、设置及阵容原图。导入先校验并展示条数；确认时下载导入前完整备份。兼容旧版 v1 备份，导入旧版时保留当前阵容。设置中也可仅导出待办与资源。
- 原有待办继续使用同一个 localStorage 存储键；阵容文字与图片使用独立 IndexedDB。保存失败提示、损坏数据只读保护、同源多标签页更新通知。阵容存储不可用时，仍可使用待办和导出待办备份。
- 手机和桌面响应式布局；背景使用 `图片/笼梦祸津神3.jpg`，设置可展开背景欣赏模式。

## 使用边界

初次资源余额为 0，请先录入真实数据。任务完成不会自动增加资源，也不连接游戏账号。截图识别与跨设备云同步留待后续开发。

任务预置是检查清单；数量、开放时间和奖励以游戏当前版本为准。神龛按实际商店周期手动重置；宴会、阴界之门为开放日检查项，不表示每天开放。详见 `奖励来源.md`。

阵容每套最多 4 张图片，单张不超过 8 MB，支持 PNG / JPG / WebP / GIF。最多 500 套阵容，图片编码合计上限 90 MB；JSON 导入文件最大 128 MB。阵容截图不进行 OCR，阵容码文本可单独粘贴。

数据仅存在当前浏览器。清理网站数据、无痕窗口结束、移动文件、换浏览器都可能影响保存。请定期导出备份。每个入口适合单页面操作，多标签页同时编辑使用最后写入的版本。

修改重置小时会改变日期归属，不迁移旧周期记录。页面只展示最近 200 条历史 / 账本，导出包含完整记录。

## 开发

- `index.html` 页面结构
- `styles.css` 响应式样式
- `core.js` 纯数据操作、周期与备份验证
- `app.js` 页面交互、阵容编辑和完整备份
- `lineup-store.js` IndexedDB 阵容存储及导入失败回滚
- `tests/core.test.cjs` 核心回归测试，安装 Node 后运行 `node tests/core.test.cjs`
- `tests/browser.test.py` 浏览器回归：安装 Python 的 `playwright` 包，启动上文的本地预览后运行 `python3 tests/browser.test.py`。默认使用 macOS 已安装的 Google Chrome，可通过 `YYS_BROWSER` 指定浏览器路径，通过 `YYS_TEST_URL` 指定预览地址。测试使用隔离的临时浏览器环境，不接触日常使用的浏览器数据；覆盖旧数据读取、桌面与手机尺寸、阵容增删改、图片校验、备份恢复、跨存储失败回滚、存储不可用保护、多页面同步与本地 HTML 入口。截图写入临时目录，可通过 `YYS_SCREENSHOTS` 指定位置。

项目使用 Git 管理，公开 GitHub 仓库：`ruotonghan39-debug/yangyangshu`。JSON 备份不纳入版本管理。

背景图片为用户提供的游戏素材，未修改原图。发布时请确认素材使用范围。
