# 痒痒鼠 · 平安手帖

阴阳师个人待办与资源管理网页。本地优先，原生 HTML / CSS / JavaScript，无依赖，不需要安装 Node 或运行服务器。

## 在线访问与部署

在线地址：https://ruotonghan39-debug.github.io/yangyangshu/

代码保存在公开 GitHub 仓库，网页通过 GitHub Pages 部署。发布源为 `main` 分支的根目录；修改代码后提交并推送到 `main`，GitHub 会自动更新网站。`.nojekyll` 用于直接发布原生静态文件。

本地网页的数据不会自动迁移到在线地址；请先导出备份，再在在线网页导入。

## 开始使用

双击本目录的 `index.html`，使用常用浏览器打开。建议固定使用同一个浏览器、同一个文件路径。浏览器若限制本地文件存储，可用 Python 启动预览：

```sh
cd ~/Documents/痒痒鼠
python3 -m http.server 8765 --bind 127.0.0.1
```

再访问 http://127.0.0.1:8765 。按 Ctrl+C 停止。文件入口与 HTTP 入口的数据彼此独立，切换时请先导出，再在新入口导入。

## 已实现

- 每日 / 每周待办：勾选、取消、搜索、状态筛选、添加、编辑、删除。
- 北京时间自动切换周期：默认每日 00:00；每周一重置周常。设置可修改重置小时。关闭网页期间无需运行，再次打开自动显示新周期。
- 历史记录：周期状态独立保存，记录勾选、取消、删除操作，支持按游戏日筛选。
- 奖励追踪：地域鬼王、秘闻竞速和分享、式神图鉴分享、常驻黑蛋黑碎检查项、一次性成就及手动刷新商店。
- 资源账本：勾玉、金币、蓝票、体力、黑蛋、黑碎；更新余额自动记录差值、备注和当时余额。
- 黑碎进度：每 50 片记一次合成，扣除 50 黑碎、增加 1 黑蛋。请在游戏中实际合成后操作。
- JSON 导出 / 导入：完整保存任务、状态、历史、资源、设置。导入先校验并展示条数；确认时下载导入前备份。
- 浏览器 localStorage 保存、保存失败提示、损坏数据只读保护、同源多标签页更新通知。
- 手机和桌面响应式布局；背景使用 `图片/笼梦祸津神3.jpg`，设置可展开背景欣赏模式。

## 使用边界

初次资源余额为 0，请先录入真实数据。任务完成不会自动增加资源，也不连接游戏账号。截图识别与跨设备云同步留待后续开发。

任务预置是检查清单；数量、开放时间和奖励以游戏当前版本为准。神龛按实际商店周期手动重置；宴会、阴界之门为开放日检查项，不表示每天开放。详见 `奖励来源.md`。

数据仅存在当前浏览器。清理网站数据、无痕窗口结束、移动文件、换浏览器都可能影响保存。请定期导出备份。每个入口适合单页面操作，多标签页同时编辑使用最后写入的版本。

修改重置小时会改变日期归属，不迁移旧周期记录。页面只展示最近 200 条历史 / 账本，导出包含完整记录。
